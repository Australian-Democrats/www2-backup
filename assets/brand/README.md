# Brand assets

The official party logos are installed here. The site references **`logo-horizontal.png`** (the full-colour "AUSTRALIAN DEMOCRATS" lockup) in every page header and footer, rendered with `mix-blend-mode` so its flat background disappears on the warm page.

## To update artwork
Replace the file **keeping the same name** — no code changes needed:

| File the site uses | Where it shows |
|---|---|
| `logo-horizontal.png` | Header + footer on join / donate / thank-you / admin |
| `logo-icon-colour.png` | Reserved for compact / square uses |
| `../../favicon.ico`, `../../favicon-240.png` | Browser tab + Google Search icon (square derivatives of `logo-icon-colour.png` — Google requires a 1:1 icon, so regenerate BOTH if the icon artwork changes) |

Your source variants (`fulltext-logo-full-colour.png`, `fulltextlogo-yellow-and-white.png`, the icon PNGs, etc.) are also kept here for future use. If you only have a differently-named file, drop it in and tell me — I'll point the pages at it. A `1200×630` `../img/social-card.png` can be added later for link previews.
